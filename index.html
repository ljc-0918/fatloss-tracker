💾 数据备份与恢复

• Excel：离线归档 / 打印 / 自己做分析，含每日总表、饮食明细、身体数据、运动消耗、目标档案。
• JSON：换手机或换浏览器时，导出后在新设备「从 JSON 恢复」即可完整迁移。
• 数据保存在本机浏览器中，建议每周导出一次备份。
• 添加到主屏：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕；安卓用 Chrome → 菜单 → 添加到主屏幕，即可像 APP 一样全屏使用。
